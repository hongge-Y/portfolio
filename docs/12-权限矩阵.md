# 12 · 权限矩阵与行级数据范围

> 一句话：**角色决定"能不能做"，orgPath 决定"能看到谁的数据"**。落到代码上是两处：`AuthService.buildPermissions()` 出权限点，各 Service 的 SQL 带范围条件。
> 回归脚本：`bash scripts/test-permissions.sh`（21 条断言，全绿）。

## 一、7 类角色 → 权限点

| 角色 | 权限点 | 说明 |
|---|---|---|
| STUDENT 学生 | leave:apply、rank:self:view、edu:timetable:view、edu:eval:submit、scholarship:apply、message:send、relative:confirm | 只能申请与看自己 |
| MONITOR 学委 | 学生全部 + leave:class:view、leave:share | 看本班已通过（20/21），理由与附件脱敏 |
| COUNSELOR 辅导员 | leave:approve、leave:class:view | 审本班、看本班 |
| SECRETARY 书记 | 同辅导员，数据范围到学院 | 审/看本学院所有班级 |
| TEACHER 授课老师 | 课表与评教相关 | 按课表班级 |
| PARENT 家长 | rank:child:view、relative:apply | 只看已绑定孩子 |
| ADMIN 管理员 | admin:all、publish:manage、org:manage | 全校 |

## 二、数据范围两档（这是行级权限的核心）

| 身份 | 范围判定 | SQL 形态 |
|---|---|---|
| 学委 / 辅导员 | 本班，精确匹配 | `AND l.class_org_id = ?`（ctx.classOrgId） |
| 书记 | 本学院，物化路径前缀 | `AND l.class_org_id IN (SELECT id FROM org_unit WHERE path LIKE CONCAT(?, '%'))`，path = ctx.orgPath（如 `/1/2/`） |
| 管理员 | 全校 | 同上，path 取 `/` |
| 家长 | 已绑定孩子 | `parent_user_id = ? AND status = 1` |
| 学生本人 | 自己 | `employee_id = ?` |

机构树用物化路径存（`org_unit.path`）：`/1/` 全校 → `/1/2/` 信息工程学院 → `/1/2/3/` 软件工程系 → `/1/2/3/4/` 软件工程2025级1班。前缀匹配天然覆盖"本院所有班级"，不用递归。

## 五、本轮的三个修复（都有回归断言兜着）

1. **书记看不到任何数据**：`classPage` 原来对所有人用 `class_org_id = ctx.classOrgId`，书记的 classOrgId 是学院 id（2），永远匹配不到班级 → 改成 orgPath 前缀，书记现在能看到本学院 16 条，管理员 17 条（含外院）。
2. **管理员 403 "未归属班级"**：admin 没有 classOrgId，原来直接抛 403 → 现在走 `/` 前缀，全校可见。
3. **跨院详情越权**：`detail()` 原来只要 `COUNSELOR/SECRETARY/ADMIN` 就放行，导致外院辅导员按 id 就能翻看别院学生的请假理由与附件（真实隐私泄漏）。现在辅导员/书记必须落在自己 orgPath 前缀内，外院一律 403。奖学金详情有同样问题，一并修了。

## 六、回归断言清单（21 条，脚本自造基线，可重复跑）

脚本自己造一张 class 7（外院）的待审假条当基线，跑完自动撤销——不依赖历史数据，`reset-demo` 清过数据也能跑。

```
未登录：班级列表 401、后台统计 401
角色：纯学生查班级列表 403、查后台 403；学委/辅导员 200；管理员 200
范围：管理员能看到外院记录；书记看不到外院记录；外院辅导员列表 total=0
详情：本班辅导员 200、本班学委 200、书记 200、管理员 200；外院辅导员 403；同班普通学生看他人 403
家长：孩子列表 200、无关假条 403
奖学金：本班辅导员 200、外院辅导员 403、书记 200
```

## 七、面试怎么讲（三句话）

1. "权限分两层：角色管权限点，orgPath 管数据范围。列表用 SQL 前缀条件收口，不靠前端藏菜单。"
2. "机构树是物化路径 `/1/2/3/4/`，书记 `/1/2/` 前缀就能覆盖本学院所有班级，不需要递归查树。"
3. "做越权测试时发现过两个真 Bug：书记一条都看不到（精确匹配 class_org_id），外院辅导员能按 id 翻别院详情。修完固化成 21 条断言，跑一次 20 秒。"
