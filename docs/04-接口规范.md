# 04 · 接口规范（API V2.0）

## 1. 统一契约

| 项 | 约定 |
|---|---|
| Base URL | 本机 `http://localhost:8106/api`；局域网（手机）`http://10.202.124.156:8106/api` |
| 版本 | 路径前缀 `/api/v1` |
| Content-Type | `application/json;charset=UTF-8`（上传为 `multipart/form-data`） |
| 鉴权 | `Authorization: Bearer <accessToken>` |
| 时间入参 | `yyyy-MM-dd HH:mm:ss`；纯日期 `yyyy-MM-dd`（**不再混用时间戳**） |
| 时间出参 | 同上字符串 |
| 布尔 | `true/false` |
| 空值 | 不返回 `null` 字段（`@JsonInclude(NON_NULL)`），前端按 undefined 处理 |
| 分页入参 | `{ "pageNum":1, "pageSize":10, "searchModel":{} }`，`pageNum` 从 1 开始，`pageSize` ≤ 100 |
| 分页出参 | `{ "pageNum":1, "pageSize":10, "total":0, "list":[] }` |
| 查询方式 | 简单列表用 `GET` + query；带筛选的分页统一 `POST /xxx/search` |
| 幂等 | 写接口支持 `Idempotency-Key` 头（选填），60s 内相同键直接返回首次结果 |

### 1.1 响应包

```json
{ "code": 200, "message": "ok", "data": {}, "traceId": "a1b2c3d4" }
```

### 1.2 错误码

| code | 场景 |
|---|---|
| 200 | 成功 |
| 400 | 参数/业务校验失败，`message` 可直接展示给用户 |
| 401 | 未登录 / accessToken 过期 |
| 403 | 已登录但无权限 |
| 404 | 资源不存在 |
| 429 | 请求过于频繁 |
| 500 | 服务端异常 |

业务子码（`message` 前缀，便于前端分支）：

| 子码 | 含义 |
|---|---|
| `CAPTCHA_INVALID` | 图形验证码错误/过期 |
| `CODE_INVALID` | 短信/邮箱验证码错误 |
| `CODE_TOO_FREQUENT` | 验证码 60s 内重复发送 |
| `LOGIN_FAIL` | 账号或密码错误 |
| `ACCOUNT_DISABLED` | 账号被禁用 |
| `LEAVE_IN_FLIGHT_LIMIT` | 在途请假已达 3 条 |
| `LEAVE_TIME_CONFLICT` | 请假时间与已有假条重叠 |
| `LEAVE_TOO_LONG` | 超过 7 天 |
| `LEAVE_STATUS_INVALID` | 当前状态不允许该操作 |
| `LEAVE_NO_COUNSELOR` | 班级未配置辅导员 |
| `RELATIVE_EXISTS` | 已存在关联或待确认申请 |
| `MATCH_REGISTER_CLOSED` | 不在报名时间 |
| `SCH_PLAN_CLOSED` | 计划不在报名期 |
| `FILE_LIMIT` | 文件数量/大小/类型超限 |

> 权限列：`-` 公开，`U` 登录即可，`S` 学生，`M` 学委，`C` 辅导员，`SC` 书记，`T` 老师，`P` 家长，`A` 管理员。

**登录返回（A6/A7/A8 统一）**

```json
{
  "code": 200,
  "data": {
    "userId": 21,
    "account": "2025000001",
    "showName": "林同学",
    "avatar": "/static/avatar/21.png",
    "accessToken": "eyJhbGciOi...",
    "refreshToken": "eyJhbGciOi...",
    "expiresIn": 7200,
    "guideDone": false,
    "needCaptcha": false
  }
}
```

**A8 密码登录 `sign` 生成规则**
原文：RSA 加密 `JSON.stringify({password, timestamp})`，公钥来自 A3，`time` 与 `timestamp` 一致。本版沿用，但明确：RSA 用 `RSA/ECB/PKCS1Padding`，公钥 base64 去掉 PEM 头尾换行，前端用 `jsencrypt`。
