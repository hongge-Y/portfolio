# 09 · 前端框架结构

> 本文是 `web/` 的**结构性说明**：为什么这样分层、每层放什么、加一个页面要动哪几处。路由以本文第 3 节和 `web/src/router/index.js` 为准。

## 1. 一句话概括

**页面不再自己画导航**。路由器给每条路由标一个 `meta.layout`，`App.vue` 据此套壳；
页面模板里只剩下"这一屏的内容"。宽度、返回条、底部 tab、未读红点、确认弹窗、加载/空/错三态，
全部由框架层统一提供。

## 2. 目录分层

```

├── layouts/                壳：页面与外界的边界
│   ├── AppShell.vue        一级页面：TopNav（桌面）+ AppBar（移动）+ TabBar（移动）
│   ├── PageShell.vue       二级页面：返回条 + 标题（桌面粘在 TopNav 下方）
│   ├── BlankLayout.vue     登录等整屏页面（不套壳）
│   └── AdminLayout.vue     管理后台：侧边栏 + 移动横滑菜单
├── components/
│   ├── layout/             壳的零件：TopNav / AppBar / TabBar / PageContainer
│   ├── common/             通用件：DataState / SectionCard / FilterChips / SegmentedTabs / ConfirmHost
│   ├── home/               首页板块（HeroCard / EntryGrid / NewsFeed / TodoPanel / ServiceStatus…）
│   └── AiAssistant.vue     全局 AI 浮球 + 抽屉
├── features/               纯逻辑（无 DOM、无 axios）：字典、状态机、展示规则
│   ├── navigation/tabs.js      一级导航唯一数据源
│   ├── navigation/adminMenu.js 后台菜单唯一数据源

├── stores/                 Pinia：user（登录态/权限）、app（未读数等全局计数）
├── utils/                  无状态工具：request / toast / format / display / crypto / sse
└── pages/                  页面（只写"这一屏"）
```

## 3. 布局机制

`router/index.js` 里每条路由声明自己属于哪种壳：

```js
{ path: '/leave', name: 'leaveList', component: () => import('@/pages/leave/LeaveList.vue'),
  meta: { layout: 'page', auth: true, title: '请假', back: '/' } }

{ path: '/message', name: 'messageList', component: () => import('@/pages/message/MessageList.vue'),
  meta: { layout: 'app', tab: 'message', auth: true, title: '消息', barTitle: '消息' } }
```

`App.vue` 用 `LAYOUTS[route.meta.layout]` 选出组件，把 `router-view` 作为默认插槽塞进去：

```vue
<component :is="layout" v-bind="route.meta.layoutProps || {}">
  <router-view v-slot="{ Component }">
    <transition name="fade-up" mode="out-in">
      <component :is="Component" :key="route.path" />
    </transition>
  </router-view>
</component>
```

| layout | 用在哪 | 提供什么 |
|---|---|---|
| `app` | 首页 / 消息 / 我的 | 桌面 TopNav、移动 AppBar、移动底部 TabBar、内容限宽 |
| `page` | 其余全部二级页 | 桌面 TopNav + 返回条、移动返回条、内容限宽；宽度由 `meta.size` 决定 |
| `blank` | 登录 | 什么都不加（整屏自绘） |
| `admin` | `/admin/*` | 深色侧边栏 + 顶栏模块标题 + 内容限宽 |

> **页面根节点必须是单个元素。** `App.vue` 用 `<Transition>` 包页面，若页面以组件为根
> （例如直接 `<DataState>`），Transition 无法动画，页面会卡在 `opacity: 0` 的进入态（表现就是白屏）。

## 4. 宽度与断点

| 项 | 约定 |
|---|---|
| 断点 | `md = 768`（平板两栏）、`lg = 1024`（桌面形态） |
| 内容宽度 | `max-w-content = 1120px`；长文 `max-w-reading = 760px`；表单 `max-w-form = 560px` |
| 容器 | `components/layout/PageContainer.vue`（`size="default|narrow|form|wide"`） |
| 内边距 | 移动 `16px`，桌面 `32px`（PageContainer 统一给，页面不再自己写 `px-4`） |

页面里判断形态一律用 `useResponsive()`，不要自己读 `window.innerWidth`。

## 5. 数据与状态三态

以前每个页面都复制一遍 `loading / errorText / list / load()`。现在只有两种写法：

```js
// 单资源
const { data, status, error, run } = useAsyncData(() => profileApi.me())
// 分页列表
const { items, total, status, error, load, next, prev } = usePagedList(
  ({ pageNum, pageSize }) => leaveApi.personal({ pageNum, pageSize, searchModel: {} })
)
```

两个 composable 都内置竞态保护（连续切筛选只有最后一次请求生效），并直接产出
`status = 'loading' | 'error' | 'empty' | 'ready'` 喂给 `<DataState>`：

```vue
<DataState :status="status" :error-text="error" empty-text="暂无记录" @retry="run">
  ...内容...
  <template #empty-extra>...</template>
</DataState>
```

## 6. 交互约定

- **二次确认**：`const { confirm } = useConfirm()` → `if (!(await confirm({ content: '确定删除？' }))) return`。
  禁止再用浏览器原生 `confirm()` / `prompt()`（样式不统一、移动端会被拦）。
- **提示**：`toast(msg, 'error')`（`utils/toast.js`）。
- **导航**：页面内一律 `router.push()`；返回由 PageShell 读 `meta.back` 处理，页面不写返回按钮。
- **未读数**：唯一来源 `stores/app.js`（`app.unread` / `app.refreshUnread()`），
  TopNav、TabBar、首页指标、消息页都读它，不再各自请求。
- **AI 浮球**：一级页面自动避让底部 tab（`fabOffsetClass`），二级页贴右下。

## 7. 加一个页面要动哪几处

1. `pages/<域>/<页面>.vue`：只写内容；根节点用单个元素。
2. `router/index.js`：加一条路由，声明 `layout`（+ 二级页的 `title` / `back` / 需要时 `size`）。
3. 若属于一级导航：先在 `features/navigation/tabs.js` 加一项，再给路由标 `meta.tab`。
4. 若属于后台：`features/navigation/adminMenu.js` 加一项 + 路由 `meta.layout: 'admin'`。
5. 状态文案/配色进 `features/<域>/*`，不要在页面里堆 `if (status === 20)`。

## 9. 已知边界

- 只有 H5 一套代码；移动端是同一套 DOM 的窄屏形态，不做小程序/App。
- 课表网格固定 12 节起，超过 12 节自动扩行；节次时间表是常量（`SECTION_TIMES`），
  学校作息不同就改那一处。
- 首页板块严格按接口返回渲染，不造演示数据；库是空的就显示空态文案。
