## 2. 全局决策（已定，可改但要全员同步）

| 项 | 决策 | 理由 |
|---|---|---|
| 架构 | 前后端分离，单仓多模块 | 团队小，便于联调 |
| 前端 | Vue 3 + Vite + TypeScript + Pinia + Tailwind CSS | 与既有技能栈一致 |
| 后端 | Spring Boot 3.0.x + MyBatis-Plus + JDK 17 | 避开 JDK 21 的 Lombok 兼容问题 |
| 数据库 | MySQL 8.0，库名 `portfolio` | 通用、校园服务器易部署 |
| 缓存 | Caffeine（开发）；预留 Redis 切面 | 单机开发足够，多实例前切 prod |
| 鉴权 | JWT（Access 2h + Refresh 7d）+ 拦截器注入 UserContext | 比 Spring Security 轻，边界清楚 |
| 接口前缀 | `/api/v1` | 与静态资源、健康检查分离 |
| 时间格式 | 收发统一 `yyyy-MM-dd HH:mm:ss` 字符串 | 避免时间戳/字符串混用 |
| 返回结构 | `Result{code,message,data,traceId}` | 前端统一拦截，日志按 traceId 串起来 |
| 权限 | 权限点 + 机构物化路径 `org_unit.path` | 行级数据范围落在 SQL，不靠前端藏菜单 |
