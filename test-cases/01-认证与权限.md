## 执行要点

- 断言判据统一是 **`code` 字段**（200/400/401/403），不是 HTTP 状态码——这是本项目的统一响应契约（见 `docs/04-接口规范.md` §1.1），写用例时两者别混。
- 脚本造外院基线时**时间段是随机的**（固定时刻会和上一轮残留单撞"时间重叠"规则，导致脚本自己造不出数据），这条是踩过的坑，别改回固定值。
- 申请 id 不能写死：冒烟脚本会清理自己造的申请，写死必然 404。
