# 04 · 家长关联、站内消息、内容可见性（REL）

**执行入口：`bash scripts/smoke-relative.sh`（19 条）+ `bash scripts/smoke-content.sh`（19 条）。**

家长关联状态机（§4.2）：`PENDING(0) —同意→ AGREED(1) —解除→ REMOVED(3)`，拒绝为 `REJECTED(2)`，同一对 `uk_pair` 复用同一条记录并重置为 0。
内容可见性（§5.5）：`内容.visible_org_id ∈ 用户组织祖先链 ∪ 子孙` ∧ `now ∈ [start,end]`；家长按已 AGREED 学生组织并集，黑榜还需 `rank.relative_visible = 1`。

## 观察项

- **UC-REL-14 是本模块最值钱的一条**：列表不出现是"过滤"能做的，但**按 id 直连详情还能拿到就是泄露**。这条断言（他院学生详情 403）是内容侧唯一的越权反例，别删。
- **TC-REL-19 的口径要现场确认**：需求写"解除后家长端历史内容保留 7 天只读"，代码里到底按 `status=3` 直接不可见，还是留了时间窗，得跑一次才知道。两种都不算错，但**简历/文档不能写一个、代码跑出另一个**。
